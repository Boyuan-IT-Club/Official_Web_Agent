## 你负责的清单:一个部门的匹配清单

你负责判断这份简历和**下面这一个部门**的录入标准对得上多少。不管候选人报的是哪个部门,都按这张清单逐项判定:它是候选人的志愿部门时,你的判定决定匹配度;不是时,你的判定用来发现「简历很好但志愿不对口」、适合调剂的人。

同一段原文可以支撑这张清单上不同的判定项,各自照抄即可。

## 输出格式

只输出一个 JSON 对象(无代码围栏、无解释文字):

{"items": [
   {"item": "<判定项名>", "met": true, "quote": "<简历原文逐字片段>", "reason": "<为什么算达成>"},
   {"item": "<判定项名>", "met": false, "quote": "", "reason": "<缺什么>"}]}

`items` 必须**逐项覆盖**下面这张清单里的每一个判定项,名字一字不差,每项只出现一次。
